# 应用外壳布局：固定框架 + 仅主内容区滚动

## 背景

`AppShell.vue` 当前最外层用 `min-h-screen`，允许整体高度撑破视口。当页面内容变长时，滚动可能发生在整个窗口而非主内容区，导致 titlebar、侧栏跟着一起被滚走，体验不稳定。

## 目标

把应用外壳锁成固定的「上 titlebar + 下(左侧栏 + 右主区)」框架，滚动只发生在右侧主内容区。

## 布局契约

- 最外层容器锁定视口高度、禁止自身溢出滚动（`h-screen` + `overflow-hidden`），纵向排布。
- 顶部 `AppTitleBar` 固定高度，不参与滚动。
- 下方为横向区域：左侧 `HSidebar` 固定，右侧 `main` 占满剩余宽度。
- 左侧栏整体高度固定、不随主区内容一起滚动。
- 右侧主区内部：更新提示条（如有）+ 页面标题 header 固定不滚，只有最下方的 `RouterView` 内容区可纵向溢出滚动。
- flex 链路各层补齐 `min-h-0` / `min-w-0`，保证 `overflow-auto` 能正确生效（避免 flex 子项被内容撑高）。

## 验收标准

- 任意页面内容超长时，titlebar 与左侧栏始终固定可见，不被滚走。
- 仅右侧主内容区出现纵向滚动条。
- 窗口没有出现整体（body/最外层）滚动条。
- 更新提示条与页面标题 header 在主区内保持固定，不随内容滚动。
- `pnpm typecheck` 通过。

## 非目标

- 不改 titlebar 自身样式（上个任务已完成）。
- 不改侧栏导航项、路由或页面内容。
- 不引入横向滚动或响应式折叠等新行为。
