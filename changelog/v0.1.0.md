# v0.1.0 (2026-08-05)

## 修复

- 修复首页「今日请求」热力图因 TDZ 变量遮蔽整块不展示的问题，统计可视化恢复。

## 功能

- 分组编辑对齐 octopus 交互：分组卡片内支持拖拽排序 / 删除成员即时保存；新建/编辑分组改为双栏选模对话框（左栏按供应商手风琴选模型、右栏已选队列拖拽管理），「拉取模型」仅在用户展开手风琴或点击时触发。
- 分组「按模型能力排序」数据源从 OpenRouter 榜单切换为 [llm_benchmark](https://github.com/llm2014/llm_benchmark) logic 综合榜（「极限分数」），展示名与 API 模型名经对称归一化分层匹配，排序语义不变（单一分数降序、未匹配沉底、稳定排序、仅改表单不自动保存）。
