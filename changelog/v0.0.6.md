# v0.0.6 (2026-07-25)

## 新增 / 变更

- 首页新增每日请求量热力图（HHeatmap），直观展示近期请求分布。
- 代理层新增分组级思考强度设置，并支持自动匹配最佳档位。
- 升级 happier-ui 至 0.0.6，并以库组件替换手写控件，视觉与交互更统一。

## 修复

- 转发前剥离 `tools.function.strict` 字段，兼容不支持该字段的上游。
- 识别 SSE 帧内错误信封，并在提交前完成换源，避免把上游错误当成成功流式返回。
- 调整 CSS 引入顺序，修复 happier-ui 组件被 Tailwind preflight 覆盖的问题。

## 安装与更新

- 安装包：GitHub Release 中的 NSIS `.exe`
- 校验：同 Release 的 `SHA256SUMS.txt`
- 应用内更新清单：`https://github.com/Happier-X/model-hub/releases/latest/download/latest.json`
