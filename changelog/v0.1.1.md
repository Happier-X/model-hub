# v0.1.1 (2026-08-06)

## 功能

- 分组新建/编辑从对话框改为独立页面：路由 `/groups/new` 与 `/groups/:id/edit`，双栏选模与保存逻辑不变，编辑长队列时不再受对话框高度限制。
- 日志页移除顶部筛选控件（分组名 / 状态 / 仅故障转移），保留每页条数、刷新、自动刷新、清理过期与清空全部。

## 内部

- 前端依赖全部升级到最新稳定版：vue-router 4→5、vite 7→8、eslint 9→10、typescript →6（TS7 编译器生态尚未就绪，有意保留 6.x）、happier-ui 0.0.6→0.1.1 等。
- 后端 Rust crate 全部升级到最新稳定版：reqwest 0.12→0.13、rusqlite 0.32→0.40、tower-http 0.6→0.7 等，保留精确锁定（`=x.y.z`）惯例。
- 验证矩阵全绿：前端 typecheck / lint / 单测(18) / build，后端 cargo check + 测试(136)，`pnpm tauri build --no-bundle` 集成编译通过。
