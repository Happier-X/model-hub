# v0.0.5 (2026-07-25)

## 新增 / 变更

- 主窗口改为无边框并新增自定义标题栏：支持拖动、最小化、最大化还原与关闭；关闭仍隐藏到托盘，代理继续运行。
- 升级 happier-ui 到 0.0.2，各页面分区卡片与侧栏改用库组件（HCard / HSidebar），视觉与交互更统一。
- 请求日志仅保留最近 7 天内的最新 1000 条，避免本地日志无限增长。

## 修复

- 故障转移候选全部耗尽时，将 2xx 错误信封升级为 502，避免向客户端返回误导性的成功状态码。
- 修复 Windows 首次建窗死锁：桌面悬浮条开关改为异步执行。

## 安装与更新

- 安装包：GitHub Release 中的 NSIS `.exe`
- 校验：同 Release 的 `SHA256SUMS.txt`
- 应用内更新清单：`https://github.com/Happier-X/model-hub/releases/latest/download/latest.json`
